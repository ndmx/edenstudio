Getting started

Use the supplied prototype build and complete the local profile flow. Discover, Network, Messages, and Profile operate on the local data model. An internet connection does not turn the prototype into a multi-device network.

Connections and sharing

Accept an incoming request to create a connection, then check exactly which fields or cards are shared. Sharing is directional: sharing your own field does not reveal another profile’s private field. A missing private detail may mean no matching grant exists.

Messages

Open Messages or a connected profile to compose. Messaging requires a connected relationship. Messages are local records, not remotely delivered messages or read receipts. Deleting a thread requires confirmation.

Blocking and reports

Manage blocked peers from Profile → Blocked accounts. Blocking removes both-direction grants and hides the peer from ordinary lists. Unblocking returns the relationship to neutral; reconnect and review grants explicitly. Reports are stored locally and are not submitted to a moderation service.

Troubleshooting

If expected information is absent, check the connection state and sharing grants first. Record the version, device/OS, action taken, and visible error. Preserve important data before reinstalling or replacing a prototype build; do not assume a server copy exists.

Contact support

Email support@edentv.us with Kasapa in the subject and steps to reproduce the issue. Redact private profile fields and messages from screenshots. Never send credentials.
